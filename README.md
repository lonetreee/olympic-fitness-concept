# OLYMPIC FITNESS Alcalá — Concept Website

Rediseño conceptual **no oficial** de una landing page para un gimnasio local de Alcalá de Henares.

## Objetivo del proyecto

La presencia web pública encontrada está principalmente enfocada a funciones para socios (acceso QR, recibos, registro y reservas). El objetivo de esta propuesta es añadir una capa comercial orientada a nuevos visitantes:

1. Explicar rápidamente qué tipo de experiencia ofrece el centro.
2. Mostrar entrenamiento, horarios y ubicación sin necesidad de iniciar sesión.
3. Crear una llamada a la acción clara para solicitar información.
4. Diseñar primero para móvil y con buena jerarquía visual.

## Stack

- HTML5
- CSS3
- JavaScript vanilla
- Sin frameworks
- Sin dependencias de pago
- Sin imágenes de terceros

## Importante

Este proyecto es una **demo de portfolio** y no es la web oficial del negocio.

- No representa ni está afiliado con OLYMPIC FITNESS.
- El contenido se ha redactado de nuevo a partir de información pública.
- No se han copiado fotografías ni textos de la web oficial.
- El sitio incluye `noindex,nofollow` para evitar que una demo con una marca real compita en buscadores.
- Antes de convertirlo en una web oficial, el propietario debe confirmar servicios, horarios, textos, marca, imágenes, datos legales y mecanismos de contacto.

## Qué cambiar si el negocio acepta el proyecto

- Sustituir el aviso de concepto por la identidad oficial.
- Añadir fotografías proporcionadas o licenciadas por el negocio.
- Verificar horarios y servicios.
- Conectar WhatsApp/teléfono/formulario.
- Añadir Aviso Legal, Privacidad y Cookies cuando corresponda.
- Sustituir `noindex,nofollow` por una configuración SEO de producción.
- Configurar dominio propio y analítica con consentimiento adecuado.
